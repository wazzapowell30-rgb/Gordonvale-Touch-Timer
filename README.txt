GORDONVALE TOUCH TIMER V3

Includes:
- Competition Timer mode
- Drop-Off Timer mode
- Drop-Off default sequence: 1-minute warning, start horn, then 2-minute intervals with three interval horns
- No voice announcement when drop-off finishes
- 7-second sports horn
- iPhone audio unlock/test button
- Offline PWA support after installation

IMPORTANT FOR IPHONE
The app must be hosted on an HTTPS website before Add to Home Screen and offline mode work correctly. Upload this folder to GitHub Pages, Netlify or Cloudflare Pages. Then open the HTTPS address in Safari, tap Share, and choose Add to Home Screen.
